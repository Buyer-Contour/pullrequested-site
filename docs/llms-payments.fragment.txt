## Paying an issued quote

Use the signed quote link provided by Phantom Pipe. For humans, open https://phantompipe.com/q/{signed_quote_token} and use Stripe Checkout (card or Link when eligible).

For agents, GET https://phantompipe.com/api/pay?quote={signed_quote_token}. The HTTP 402 JSON challenge specifies amount, currency, quote ID, expiry and nonce. Use the key at payment.stripe.publishable_key and Stripe.js (https://docs.stripe.com/js/payment_methods/create_payment_method) to create a fresh, unattached card PaymentMethod for the quote. POST JSON with nonce and payment_method (the returned pm_ ID) to the same URL. Agents with Stripe Shared Payment Tokens can send shared_payment_token instead. Never send raw card details to the quote endpoint.

Then GET the same URL with X-PAYMENT set to the returned payment_intent_id. HTTP 200 is a paid receipt; HTTP 409 means a duplicate payment or replay was rejected. This is quote-pay-v1, not native x402 or MPP.

Tempo MPP is pending production verification. Once enabled, GET https://phantompipe.com/api/mpp/pay?quote={signed_quote_token} with an MPP client. The HTTP 402 challenge uses WWW-Authenticate: Payment, method tempo, intent charge, and specifies the quote amount in OUSD. Retry with Authorization: Payment. HTTP 200 includes Payment-Receipt and an on-chain transaction hash; HTTP 409 rejects replay. Fund with OUSD on Tempo, not MACH, and do not attempt another rail while a payment is in flight.
